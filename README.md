# go-patterns-lab

Репозиторий с понятными разборами паттернов и запускаемыми примерами на Go.

Здесь будут классические паттерны проектирования, Go concurrency patterns и практические приёмы, которые встречаются в реальном коде.

## Что входит в разбор

- какую проблему решает паттерн
- как он устроен
- реализация на Go
- полный пример, который можно запустить
- ограничения и типичные ошибки

## Запуск примеров

Перейди в каталог нужного примера и выполни:

```bash
go run .
```

Репозиторий постепенно пополняется.
