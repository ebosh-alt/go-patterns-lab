# Реализация на Go

В Go нет наследования классов, поэтому классический Шаблонный метод удобно адаптировать через интерфейсы и композицию.

В каталоге находятся два независимых примера. Они используют разные предметные области, но следуют одной идее: общий алгоритм хранит порядок операций, конкретная реализация отвечает за отдельные шаги.

## Вариант 1. Отправка одноразового кода

Пример в каталоге [`otp`](otp) моделирует создание и отправку OTP через SMS или email.

`OTPService.GenerateAndSend` фиксирует последовательность:

```text
Generate -> Save -> Message -> Send
```

Компоненты примера:

- `OTPFlow` описывает изменяемые шаги алгоритма
- `OTPService.GenerateAndSend` является шаблонным методом
- `BaseOTPFlow` содержит общую реализацию создания и сохранения кода
- `SMSFlow` и `EmailFlow` определяют подготовку и отправку сообщения
- клиент выбирает канал доставки, не изменяя общий алгоритм

При добавлении push-уведомлений достаточно реализовать `OTPFlow`. Порядок создания и отправки кода останется прежним.

Запуск:

```bash
go run ./template-method/example/otp
```

## Вариант 2. Импорт данных

Пример в каталоге [`data-import`](data-import) импортирует пользователей из CSV и JSON.

`Importer.Import` фиксирует последовательность:

```text
Parse -> Validate -> Transform -> Save
```

Компоненты примера:

- `ImportFormat` описывает разбор, проверку и преобразование записей
- `Importer.Import` является шаблонным методом
- `CSVFormat` реализует работу с CSV
- `JSONFormat` реализует работу с JSON
- `Repository` отделяет алгоритм импорта от способа хранения
- `MemoryRepository` сохраняет результат в памяти

Если любой шаг возвращает ошибку, алгоритм останавливается. Например, при ошибке валидации преобразование и сохранение уже не выполняются.

Добавление XML потребует новой реализации `ImportFormat`, но не изменения `Importer.Import`.

Запуск:

```bash
go run ./template-method/example/data-import
```

Ожидаемый результат:

```text
CSV: импортировано пользователей: 2
- Анна <anna@example.com>
- Иван <ivan@example.com>

JSON: импортировано пользователей: 2
- Мария <maria@example.com>
- Пётр <petr@example.com>
```

## Тесты

Из корня репозитория:

```bash
go test ./...
```

Тесты проверяют порядок шагов обоих шаблонных методов, передачу ошибок, импорт CSV и импорт JSON.
