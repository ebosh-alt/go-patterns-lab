# История команд и отмена

Этот пример показывает отмену действия. `ReplaceTextCommand` перед заменой текста запоминает предыдущее значение. `History` выполняет команду, кладёт её в стек и по `Undo` отменяет последнюю операцию.

Если выполнить две команды, отмена пойдёт в обратном порядке: сначала будет отменено последнее изменение, затем предыдущее.

## Структура

- [`editor.go`](editor.go) содержит получатель `Editor` и команду замены текста;
- [`history.go`](history.go) содержит интерфейс отменяемой команды и стек истории;
- [`main.go`](main.go) заменяет текст и отменяет замену;
- [`undo_test.go`](undo_test.go) проверяет восстановление текста и порядок отмены.

## Запуск

Из корня репозитория:

```bash
go run ./command/example/undo
go test ./command/example/undo
```

Ожидаемый вывод:

```text
Пост опубликован
Черновик
```
