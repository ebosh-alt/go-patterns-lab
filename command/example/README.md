# Реализация Command на Go

Каталог содержит три самостоятельных примера. Они показывают базовое разделение отправителя и получателя, отложенное выполнение и отмену операций.

| Версия | Что показывает | Ограничение |
|---|---|---|
| [`basic`](basic/) | Кнопки включают и выключают телевизор через команды | Нет истории и отмены |
| [`queue`](queue/) | Команды хранятся и выполняются позднее в заданном порядке | Очередь выполняет все задачи сразу |
| [`undo`](undo/) | История отменяет последнее изменение текста | Есть только отмена, без повтора |

## Запуск

Из корня репозитория:

```bash
go run ./command/example/basic
go run ./command/example/queue
go run ./command/example/undo
```

## Тестирование

```bash
go test ./command/example/...
```
