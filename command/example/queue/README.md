# Очередь отложенных команд

Этот пример показывает, зачем команда должна быть отдельным объектом. `Queue` принимает команды через `Add`, но не выполняет их сразу. Выполнение начинается только после `RunAll`.

Порядок в очереди сохраняется: сначала собирается отчёт, затем он отправляется. После выполнения очередь очищается, поэтому команда не запускается повторно при следующем `RunAll`.

## Структура

- [`queue.go`](queue.go) содержит интерфейс `Command`, адаптер `CommandFunc` и очередь;
- [`main.go`](main.go) добавляет две задачи и выполняет их;
- [`queue_test.go`](queue_test.go) проверяет отложенное выполнение, порядок и очистку очереди.

## Запуск

Из корня репозитория:

```bash
go run ./command/example/queue
go test ./command/example/queue
```

Ожидаемый вывод:

```text
Команды добавлены в очередь
Собрать отчёт
Отправить отчёт
```
