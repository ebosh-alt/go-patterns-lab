# Базовая команда для кнопок

Пример показывает минимальную структуру Command. Две кнопки управляют одним телевизором, но не зависят от типа `TV`: каждая хранит только интерфейс `Command` и вызывает `Execute`.

`OnCommand` и `OffCommand` знают получателя `Device` и передают ему вызовы `On` и `Off`. Поэтому одну команду можно назначить кнопке на пульте, кнопке на корпусе телевизора или другому отправителю без дублирования логики.

## Структура

- [`command.go`](command.go) содержит интерфейс `Command` и команды включения и выключения;
- [`button.go`](button.go) содержит отправитель `Button`;
- [`device.go`](device.go) содержит интерфейс получателя `Device`;
- [`tv.go`](tv.go) содержит получатель `TV`;
- [`main.go`](main.go) связывает объекты и запускает команды;
- [`command_test.go`](command_test.go) проверяет изменение состояния телевизора.

## Запуск

Из корня репозитория:

```bash
go run ./command/example/basic
go test ./command/example/basic
```

Ожидаемый вывод:

```text
Телевизор включён
Телевизор выключен
```
